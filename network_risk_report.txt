network scanned: 192.168.0.0/24
wifi security: UNKNOWN

wifi note: Not sure what Wi-Fi security is being used.

what this project does:
- finds devices on a home network
- checks common ports
- gives a risk score
- uses STRIDE to explain the risk
- compares WEP, WPA, WPA2, and WPA3
- gives basic fixes

wifi comparison:
- WEP: very high risk. WEP is really old and should not be used anymore.
- WPA: high risk. WPA is old too. It is better than WEP, but still not great.
- WPA2: medium risk. WPA2 is pretty normal. It is okay if your Wi-Fi password is strong.
- WPA3: low risk. WPA3 is the best common home Wi-Fi option right now.
